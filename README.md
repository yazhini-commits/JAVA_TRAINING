# CTS Digital Nurture Program - Java Training

This repository contains the programs, assignments, hands-on exercises, and project work completed during the Cognizant Digital Nurture Program (DNP) Java Training.

## Topics Covered
- Core Java Fundamentals
- Object-Oriented Programming (OOP)
- Exception Handling
- Collections Framework
- Java 8 Features
- File Handling
- JDBC
- Unit Testing
- Maven
- Spring Framework Basics
- Hands-on Exercises and Assignments

## Objective
To strengthen Java programming skills and gain practical exposure to industry-standard software development practices through the Cognizant Digital Nurture Program.
