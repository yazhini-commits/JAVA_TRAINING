1. Unary Plus (+)
----------------------
Purpose: It simply returns the value of the operand, but is mostly used to indicate a positive value explicitly (which is redundant for numeric types).

Example:

int a = 5;
int result = +a;  // result will be 5

2. Unary Minus (-)
-----------------------
Purpose: It negates the value of the operand.

Example:

int a = 5;
int result = -a;  // result will be -5

3. Increment (++)
-----------------------
Purpose: It increases the value of the operand by 1.

Pre-increment: ++a increments the value before it is used.

Post-increment: a++ increments the value after it is used.

Example:

int a = 5;
int preIncrement = ++a;  // a becomes 6, preIncrement will be 6
int postIncrement = a++; // postIncrement will be 6, a becomes 7


4. Decrement (--)
-----------------------
Purpose: It decreases the value of the operand by 1.

Pre-decrement: --a decrements the value before it is used.

Post-decrement: a-- decrements the value after it is used.

Example:

int a = 5;
int preDecrement = --a;  // a becomes 4, preDecrement will be 4
int postDecrement = a--; // postDecrement will be 4, a becomes 3


5. Logical NOT (!)
-----------------------
Purpose: It negates a boolean value.

Example:

boolean flag = true;
boolean result = !flag;  // result will be false
These operators can be used with variables or expressions of suitable types.


bitwise operator
-----------------------
In Java, bitwise operators are used to perform operations on the binary representations of integers (i.e., int, long, short, byte, etc.). These operators perform bit-level operations, which can be very useful for low-level programming tasks like manipulating flags, performing fast calculations, or working with hardware.

Here are the main bitwise operators in Java:

1. Bitwise AND (&)
-----------------------
Purpose: Compares each bit of two operands. The result is 1 if both bits are 1, otherwise 0.

Example:

int a = 5;   // 0101 in binary
int b = 3;   // 0011 in binary
int result = a & b;  // 0001 in binary (which is 1 in decimal)
System.out.println(result);  // Output: 1

2. Bitwise OR (|)
-----------------------
Purpose: Compares each bit of two operands. The result is 1 if at least one of the bits is 1, otherwise 0.

Example:

int a = 5;   // 0101 in binary
int b = 3;   // 0011 in binary
int result = a | b;  // 0111 in binary (which is 7 in decimal)
System.out.println(result);  // Output: 7


3. Bitwise XOR (^)
-----------------------
Purpose: Compares each bit of two operands. The result is 1 if the bits are different, otherwise 0.

Example:

int a = 5;   // 0101 in binary
int b = 3;   // 0011 in binary
int result = a ^ b;  // 0110 in binary (which is 6 in decimal)
System.out.println(result);  // Output: 6


4. Bitwise Complement (~)
-------------------------------------
Purpose: Flips all the bits of the operand. All 1 bits become 0, and all 0 bits become 1.

Example:

int a = 5;   // 0101 in binary
int result = ~a;  // 1010 in binary (which is -6 in decimal due to two's complement representation)
System.out.println(result);  // Output: -6


5. Left Shift (<<)
-------------------------------------
Purpose: Shifts the bits of the operand to the left by the specified number of positions. The empty bits on the right are filled with 0s.

Each left shift operation is like multiplying the number by 2.

Example:

int a = 5;   // 0101 in binary
int result = a << 1;  // 1010 in binary (which is 10 in decimal)
System.out.println(result);  // Output: 10


6. Right Shift (>>)
-------------------------------------
Purpose: Shifts the bits of the operand to the right by the specified number of positions. For signed integers, the leftmost bits are filled with the sign bit (i.e., 0 for positive numbers, 1 for negative numbers).

Each right shift operation is like dividing the number by 2 (and discarding any remainder).

Example:

int a = 5;   // 0101 in binary
int result = a >> 1;  // 0010 in binary (which is 2 in decimal)
System.out.println(result);  // Output: 2
