1. WHAT IS DOM?
--------------------------------------------------------

DOM = Document Object Model

The DOM represents an HTML document as a tree structure.

JavaScript uses the DOM to:

✓ Access HTML elements
✓ Modify HTML content
✓ Change CSS styles
✓ Handle events
✓ Create/Delete elements dynamically

Example HTML:

<html>
<body>
   <h1>Hello</h1>
   <p>Welcome</p>
</body>
</html>

DOM Tree:

Document
|
|-- html
    |
    |-- body
        |
        |-- h1
        |
        |-- p

B. getElementsByClassName()

Select elements using class.

HTML:

JavaScript:

let data =

Returns:
HTMLCollection

HTML:

<p>Hello</p>

JavaScript:

D. querySelector()

Returns first matching element.

HTML:

<p class="msg">One</p>
<p class="msg">Two</p>

JavaScript:

document.querySelector(".msg");

console.log(para);

E. querySelectorAll()

Returns all matching elements.

JavaScript:
