OOPS
=======
OOPS Foundation
======================

1. Class
========

A class is a blueprint or template used to create objects.

It defines:

Attributes (variables / data)

Methods (functions / behavior)

Example:
===========
class Car {
    String brand;
    int speed;

    void drive() {
        System.out.println("Car is running");
    }
}


Here:
======
Car → Class

brand, speed → Attributes

drive() → Method


===================================================

2. Object
===========
An object is a real instance of a class.

If class = blueprint
Object = real product created from blueprint

Example:
===========

public class Main {
    public static void main(String[] args) {

        Car c1 = new Car();   // Object creation

        c1.brand = "BMW";
        c1.speed = 120;

        c1.drive();
    }
}

c1 is an object of class Car.

===================================================


3. Constructor

A constructor is a special method used to initialize object values.

Rules:

Constructor name = Class name

No return type (not even void)

Automatically called when object is created


**  Types of Constructor

1. Default Constructor
===================================================
No parameters.

class Car {
    String brand;

    Car() {   // Default constructor
        brand = "Unknown";
    }
}

2. Parameterized Constructor
===================================

Takes parameters.

class Car {
    String brand;
    int speed;

    Car(String b, int s) {
        brand = b;
        speed = s;
    }
}

Usage:

Car c1 = new Car("Audi", 150);


3. Constructor Overloading
===============================

Multiple constructors in same class.

class Car {
    String brand;
    int speed;

    Car() {
        brand = "Unknown";
    }

    Car(String b) {
        brand = b;
    }

    Car(String b, int s) {
        brand = b;
        speed = s;
    }
}

* Same constructor name, different parameters.

===================================================


4. Attributes (Variables)


Attributes are variables inside a class.

** Types of Attributes

1. Instance Variable
===============================
Belongs to object.

class Student {
    String name;   // instance variable
}

Each object gets its own copy.

2. Static or Class Variable
===============================

Belongs to class, shared by all objects.

class Student {
    static String school = "ABC School";
}

Access without object:

System.out.println(Student.school);

3. Local Variables
====================
class Test {
    int a = 10;   // instance variable

    void display() {
        int b = 20;  // local variable
    }
}

===================================================


5. Methods (Functions)


Methods define behavior of objects.


class Calculator {
    int add(int a, int b) {
        return a + b;
    }
}

Usage:

Calculator c = new Calculator();
System.out.println(c.add(5, 3));

** Types of Methods

1. Instance Method
===============================

Needs object.

class Dog {
    void bark() {
        System.out.println("Dog is barking");
    }
}

Call:

Dog d = new Dog();
d.bark();

2. Static Method
===============================

Belongs to class.

class MathUtils {
    static int square(int x) {
        return x * x;
    }
}

Call:

System.out.println(MathUtils.square(4));

No object needed.

6. Static Keyword
===================

static means it belongs to the class, not to object.

Can be used with:

	* Variables

	* Methods

	* Nested classes

Example:

class Counter {
    static int count = 0;

    Counter() {
        count++;
    }
}

All objects share the same count.

7. this keyword
=================

this is a reference variable that refers to the current object

* Why this is Needed?

When instance variables and local variables / parameters have same name.

Without this, Java gets confused.


Example:  Without this
========================
class Student {
    String name;

    Student(String name) {
        name = name;     }
}

Here:

name parameter hides instance variable.

Instance variable never gets value.


Example:  Using this
========================

class Student {
    String name;

    Student(String name) {
        this.name = name;   // instance = parameter
    }
}

* this.name → instance variable
* name → constructor parameter

Example:

class Main {
    public static void main(String[] args) {

        Employee e1 = new Employee("Alex", 25, 50000);
        Employee e2 = new Employee();

        e1.incrementSalary(5000);
        e1.display();

        e2.display();

        Employee.showCompany();
    }
}
class Employee {

    // Instance variables
    String name;
    int age;
    double salary;

    // Static variable
    static String company = "TechCorp";

    // Default constructor
    Employee() {
        this("Unknown", 0, 0.0);   // constructor chaining
    }

    // Parameterized constructor
    Employee(String name, int age, double salary) {
        this.name = name;
        this.age = age;
        this.salary = salary;
    }

    // Normal instance method
    void incrementSalary(double amount) {
        this.salary += amount;
    }

    // Instance method
    void display() {
        System.out.println("Name: " + this.name);
        System.out.println("Age: " + this.age);
        System.out.println("Salary: " + this.salary);
        System.out.println("Company: " + company);
        System.out.println("-------------------");
    }

    // Static method
    static void showCompany() {
        System.out.println("Company Name: " + company);
    }
}

Constructor

1) copy constructor
--------------------------
A copy constructor is typically used to create a new object that is a copy of an existing object. It takes an object of the same class as a parameter.

Example:

class Person {
    String name;
    int age;

    // Default constructor
    public Person() {
        this.name = "abc";
        this.age = 0;
    }

    // Copy constructor
    public Person(Person other) {
        this.name = other.name;
        this.age = other.age;
    }

    // Method to display information
    public void display() {
        System.out.println("Name: " + name + ", Age: " + age);
    }
}

public class Main {
    public static void main(String[] args) {
        Person person1 = new Person();
        person1.display();

        // Using the copy constructor
        Person person2 = new Person(person1);
        person2.display();
    }
}

2) Constructor chaining
-----------------------------
Constructor chaining in Java refers to calling one constructor from another within the same class. You do this using this().

Example:

class Car {
    String model;
    int year;

    public Car() {
        this("BMW", 1980);
    }

    public Car(String model, int year) {
        this.model = model;
        this.year = year;
    }

    public void display() {
        System.out.println("Model: " + model + ", Year: " + year);
    }
}

public class Main {
    public static void main(String[] args) {
        Car car1 = new Car();
        car1.display();

        Car car2 = new Car("Tesla", 2023);  
        car2.display();
    }
}

3) this keyword
--------------------------
* this keyword is a reference variable that refers to the current instance of the class. 
* It is used within an instance method or a constructor to refer to the object on which the method was invoked or the constructor was called.

class Calculator {
    int result;

    public void add(int num1, int num2) {
        this.result = num1 + num2;  // Using 'this' to refer to the instance variable
    }


    public void displayResult() {
        System.out.println("Result: " + this.result);
    }


    public void calculateAndDisplay(int num1, int num2) {
        this.add(num1, num2);  // Calling another instance method using 'this'
        this.displayResult();
    }
}

public class Main {
    public static void main(String[] args) {
        Calculator calc = new Calculator();
        calc.calculateAndDisplay(5, 7);
    }
}

Example:-

4) Multiple Inheritance (Using Interfaces)
***********************************************

Java does not support multiple inheritance directly with classes, meaning a class cannot inherit from more than one class. 
However, multiple inheritance can be achieved using interfaces.


An interface in Java is a blueprint of a class.

It contains:

	abstract methods
	constants (public static final variables)
What a class should do, not how it should do it.

Example:-

interface Animal {
    void sound();
}

interface Pet {
    void play();
}

class Dog implements Animal, Pet {
    @Override
    public void sound() {
        System.out.println("Dog barks");
    }

    @Override
    public void play() {
        System.out.println("Dog plays fetch");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.sound();  
        dog.play();  
    }
}

######################################################
5) Hybrid Inheritance

* Hybrid inheritance refers to a combination of two or more types of inheritance. 
* In Java, hybrid inheritance is possible when interfaces are involved, as Java does not allow multiple inheritance through classes.

Example:-

interface Animal {
    void sound();
}

interface Pet {
    void play();
}

class Dog {
    void eat() {
        System.out.println("Dog is eating");
    }
}

class PetDog extends Dog implements Animal, Pet {
    @Override
    public void sound() {
        System.out.println("PetDog barks");
    }

    @Override
    public void play() {
        System.out.println("PetDog plays fetch");
    }
}

public class Main {
    public static void main(String[] args) {
        PetDog petDog = new PetDog();
        petDog.eat();    // From Dog class
        petDog.sound();  // From Animal interface
        petDog.play();   // From Pet interface
    }
}

6) Is-A Relationship (normal Inheritance)
----------------------------------------------------------------

*) The Is-A relationship refers to the concept where one class is a specific type of another class. 
*) This relationship is represented through inheritance.

Example: A Dog is a type of Animal. This means that a Dog inherits properties and behaviors from the Animal class.
Example of Is-A Relationship (Inheritance):

class Animal {
    void eat() {
        System.out.println("Animal is eating");
    }
}

class Dog extends Animal {  // Dog IS-A Animal
    void bark() {
        System.out.println("Dog is barking");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.eat();   // Inherited from Animal class
        dog.bark();  // Specific to Dog class
    }
}

----------------------------------------------------------------

7) HAS-A Relationship (object based relation)
-----------------------------------------------------------

*) In this type of relationship, one class contains a reference to objects of another class. 
*) These are both forms of association but differ in the level of dependency between the objects.

Example:-
=================

class Book {
    void read() {
        System.out.println("Reading the book");
    }
}

class Library {
    Book book;  // Library HAS-A Book

    Library(Book book) {
        this.book = book;
    }

    void showBook() {
        book.read();  // Calling method of Book class
    }
}

public class Main {
    public static void main(String[] args) {
        Book book = new Book();
        Library library = new Library(book);
        library.showBook();  // Output: Reading the book
    }
}

Polymorphism
----------------------

Most commen polymorphism types are method overloading and method overriding.

Method Overloading: When two or more methods in the same class have the same name but different parameters (either type or number).

Method Overriding: When a subclass provides a specific implementation for a method that is already defined in its superclass.


Compile-time Polymorphism (Method Overloading)
___________________________________________________________

class Calculator {
    // Method to add two integers
    public int add(int a, int b) {
        return a + b;
    }

    // Overloaded method to add three integers
    public int add(int a, int b, int c) {
        return a + b + c;
    }

    // Overloaded method to add two doubles
    public double add(double a, double b) {
        return a + b;
    }
}

public class Main {
    public static void main(String[] args) {
        Calculator calc = new Calculator();

        // Calling different overloaded methods
        System.out.println("Sum of 2 integers: " + calc.add(2, 3));        
        System.out.println("Sum of 3 integers: " + calc.add(1, 2, 3));     
        System.out.println("Sum of 2 doubles: " + calc.add(2.5, 3.5));     
    }
}

Runtime Polymorphism (Method Overriding)
____________________________________________________
// Superclass
class Animal {
    public void makeSound() {
        System.out.println("Animal makes a sound");
    }
}

// Subclass
class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Dog barks");
    }
}

// Another subclass
class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Cat meows");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog animal1 = new Dog();  
        Cat animal2 = new Cat();  
        Animal animal3 = new Animal(); 
        
        animal1.makeSound();  
        animal2.makeSound();  
        animal3.makeSound();
    }
}

Abstraction
----------------
Hiding internal properties and only showing functionality.

Constraints of Abstract Class
1. Abstract Class Cannot Be Instantiated
2. Abstract Method Has No Body
3. If Class Contains Abstract Method, Class Must Be Abstract
4. Subclass Must Implement Abstract Methods
5. Abstract Class Can Have
	Abstract methods
	Normal methods
	Constructors
	Variables
6. Abstract Methods Cannot Be Private
7. Abstract Method Cannot Be Final
8. Abstract Class Can Have Static Methods



Example:-

// Abstract class
abstract class Animal {
    abstract void sound(); // Abstract method (no implementation)

    public void sleep() {
        System.out.println("Animal is sleeping");
    }
}



class Dog extends Animal{
    // Providing implementation for the abstract method in Animal
    public void sound() {
        System.out.println("Dog barks");
    }

    public void run() {
        System.out.println("Dog is running");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.sound();  
        dog.sleep();  
        dog.run();    
    }
}

*) final Keyword 
++++++++++++++++++++

1) final keyword is used to declare constants, prevent method overriding, and prevent class inheritance. 
2) It can be applied to variables, methods, and classes with different effects.


1) final Variable
----------------------
When a variable is declared as final, its value cannot be changed once it is assigned. It essentially makes the variable a constant.

Syntax:

final dataType variableName = value;

Example:
class Example {
    final int MAX_LIMIT = 100;  // final variable

    void showLimit() {
        MAX_LIMIT = 80;
        System.out.println("The max limit is: " + MAX_LIMIT);
    }
}

public class Main {
    public static void main(String[] args) {
        Example obj = new Example();
        obj.showLimit();  
    }
}

+++++++++++++++++++++++++++++++++++++++++++

2) final Method
---------------------
A final method cannot be overridden by any subclass. 
This is useful when you want to ensure that the method's implementation is not modified in subclasses.

Example:-
--------------------
class Animal {
    final void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog extends Animal {
    void sound() {  
        System.out.println("Dog barks");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal animal = new Animal();
        animal.sound();
    }
}
----------------------------

3) final Class
---------------------------
A final class cannot be subclassed. 
This is useful when you want to create a class that should not be extended or modified by other classes.

example:-
final class Car {
    void drive() {
        System.out.println("Driving the car");
    }
}

class ElectricCar extends Car { 
    void charge() {
        System.out.println("Charging the car");
    }
}

public class Main {
    public static void main(String[] args) {
        Car car = new Car();
        car.drive(); 
    }
}

Super keyword:
____________________________

*) The super keyword refers to superclass (parent) objects.

*) It is used to call superclass methods, and to access the superclass constructor.

*) The most common use of the super keyword is to eliminate the confusion between super classes and subclasses that have methods with the same name.

Example:
-----------------

class Animal { // (parent)
  public void animalSound() {
    System.out.println("The animal makes a sound");
  }
}

class Dog extends Animal { // (child)
  public void animalSound() {
    super.animalSound(); // Call the superclass method
    System.out.println("The dog says: bow wow");
  }
}

public class Main {
  public static void main(String args[]) {
    Animal myDog = new Dog(); 
    myDog.animalSound(); 
  }
}
--------------

        super(); // calls Parent()

}

public class Main {

    }
