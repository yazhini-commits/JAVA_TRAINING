String methods in JAVA
-_-_-_-_-_-_-_-_-_-_-_-_-_-_


1. length()
Returns the length of the string.

String str = "Hello, world!";
System.out.println(str.length()); // Output: 13


2. charAt(int index)
Returns the character at the specified index.

String str = "Hello";
System.out.println(str.charAt(1)); // Output: 'e'


3. substring(int start)
Returns a new string that is a substring starting from the specified index to the end of the string.

String str = "Hello, world!";
System.out.println(str.substring(7)); // Output: "world!"


4. substring(int start, int end)
Returns a new string that is a substring from the start index (inclusive) to the end index (exclusive).

String str = "Hello, world!";
System.out.println(str.substring(0, 5)); // Output: "Hello"


5. indexOf(String str)
Returns the index of the first occurrence of the specified substring.

String str = "Hello, world!";
System.out.println(str.indexOf("world")); // Output: 7


6. indexOf(char ch)
Returns the index of the first occurrence of the specified character.

String str = "Hello";
System.out.println(str.indexOf('l')); // Output: 2


7. lastIndexOf(String str)
Returns the index of the last occurrence of the specified substring.



String str = "Hello, world!";
System.out.println(str.lastIndexOf("o")); // Output: 8


8. lastIndexOf(char ch)
Returns the index of the last occurrence of the specified character.



String str = "Hello";
System.out.println(str.lastIndexOf('l')); // Output: 3


9. equals(Object obj)
Compares the string to the specified object.


String str1 = "Hello";
String str2 = "Hello";
System.out.println(str1.equals(str2)); // Output: true


10. equalsIgnoreCase(String anotherString)
Compares the string to the specified string, ignoring case differences.

String str1 = "Hello";
String str2 = "hello";
System.out.println(str1.equalsIgnoreCase(str2)); // Output: true


11. toLowerCase()
Converts all characters in the string to lowercase.

String str = "HELLO";
System.out.println(str.toLowerCase()); // Output: "hello"


12. toUpperCase()
Converts all characters in the string to uppercase.

String str = "hello";
System.out.println(str.toUpperCase()); // Output: "HELLO"


13. trim()
Removes any leading and trailing whitespace from the string.

String str = "  Hello, world!  ";
System.out.println(str.trim()); // Output: "Hello, world!"


14. replace(char oldChar, char newChar)
Returns a new string with all occurrences of the old character replaced with the new character.

String str = "Hello, world!";
System.out.println(str.replace('o', '0')); // Output: "Hell0, w0rld!"


15. replaceAll(String regex, String replacement)
Replaces each substring of the string that matches the given regular expression with the given replacement.



String str = "Hello 123 World";
System.out.println(str.replaceAll("\\d", "*")); // Output: "Hello *** World"


16. split(String regex)
Splits the string around matches of the given regular expression.

String str = "apple,banana,orange";
String[] fruits = str.split(",");
for (String fruit : fruits) {
    System.out.println(fruit); 
}
// Output:
// apple
// banana
// orange

17. startsWith(String prefix)
Checks if the string starts with the specified prefix.

String str = "Hello, world!";
System.out.println(str.startsWith("Hello")); // Output: true


18. endsWith(String suffix)
Checks if the string ends with the specified suffix.

String str = "Hello, world!";
System.out.println(str.endsWith("world!")); // Output: true


19. contains(CharSequence sequence)
Checks if the string contains the specified sequence of characters.

String str = "Hello, world!";
System.out.println(str.contains("world")); // Output: true


20. isEmpty()
Checks if the string is empty (length is 0).

String str = "";
System.out.println(str.isEmpty()); // Output: true


21. valueOf(int i)
Returns the string representation of the specified integer.

int num = 123;
System.out.println(String.valueOf(num)); // Output: "123"


22. format(String format, Object... args)
Returns a formatted string using the specified format and arguments.

String str = String.format("Hello, %s!", "World");
System.out.println(str); // Output: "Hello, World!"


23. concat(String str)
Concatenates the specified string to the end of the current string.

String str1 = "Hello";
String str2 = " World!";
System.out.println(str1.concat(str2)); // Output: "Hello World!"


24. String.join(CharSequence delimiter, CharSequence... elements)
Joins multiple strings with a specified delimiter.


String str = String.join(", ", "apple", "banana", "orange");
System.out.println(str); // Output: "apple, banana, orange"


25. toCharArray()
Converts the string to an array of characters.

String str = "Hello";
char[] chars = str.toCharArray();
for (char c : chars) {
    System.out.println(c);
}
// Output:
// H
// e
// l
// l
// o


26. compareTo(String anotherString)
Compares two strings lexicographically.

String str1 = "apple";
String str2 = "banana";
System.out.println(str1.compareTo(str2)); // Output: -1 (because "apple" is lexicographically less than "banana")



27. compareToIgnoreCase(String anotherString)
Compares two strings lexicographically, ignoring case differences.


String str1 = "apple";
String str2 = "APPLE";
System.out.println(str1.compareToIgnoreCase(str2)); // Output: 0 (because "apple" and "APPLE" are the same ignoring case)
