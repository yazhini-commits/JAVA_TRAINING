Java Array Methods (Using java.util.Arrays)

Note: import java.util.Arrays; is required for these methods.

1. toString(array)
------------------
Converts array to a readable string.
Example:
int[] arr = {1, 2, 3};
System.out.println(Arrays.toString(arr));  // Output: [1, 2, 3]

2. sort(array)
--------------
Sorts array in ascending order.
Example:
int[] arr = {3, 1, 2};
Arrays.sort(arr);  // arr → [1, 2, 3]

3. copyOf(array, newLength)
---------------------------
Copies array to a new array with specified length.
Example:
int[] a = {1, 2, 3};
int[] b = Arrays.copyOf(a, 5);  // [1, 2, 3, 0, 0]

4. copyOfRange(array, from, to)
-------------------------------
Copies a specific range (end index is exclusive).
Example:
int[] a = {10, 20, 30, 40};
int[] sub = Arrays.copyOfRange(a, 1, 3);  // [20, 30]

5. fill(array, value)
---------------------
Fills the array with the given value.
Example:
int[] arr = new int[5];
Arrays.fill(arr, 7);  // [7, 7, 7, 7, 7]

6. equals(arr1, arr2)
---------------------
Checks if two arrays are equal in content and order.
Example:
int[] a = {1, 2};
int[] b = {1, 2};
System.out.println(Arrays.equals(a, b));  // true

7. binarySearch(array, value)
-----------------------------
Searches for a value in a sorted array using binary search.
Example:
int[] a = {1, 2, 3, 4, 5};
int index = Arrays.binarySearch(a, 3);  // Output: 2
